# FPFT Lab 콘텐츠 관리 가이드

홈페이지의 자주 바뀌는 정보는 `data/`의 JSON 파일로 관리합니다.

- `research.json`: 연구분야와 현재 연구주제
- `projects.json`: 현재 수행 연구과제
- `publications.json`: 논문
- `members.json`: 구성원
- `activities.json`: 학회·수상·연구실 활동

## 권장 편집 방법

일상적인 업데이트는 JSON을 직접 수정하지 말고 아래 관리자 화면을 사용합니다.

**https://cnu-fpft-lab.github.io/admin/**

Decap Turbo 연결이 끝나면 다음 작업을 웹 폼에서 수행할 수 있습니다.

- 논문 추가·수정·삭제 및 순서 변경
- 학회·수상·연구실 활동 추가
- 활동 사진 업로드
- 구성원 추가·수정 및 프로필 사진 업로드
- 연구과제 추가·수정
- 연구분야와 세부 주제 수정

이미지 업로드 파일은 기본적으로 `assets/uploads/`에 저장됩니다.

## 논문 입력 형식

현재 논문 목록은 기존 서지 형식을 그대로 유지하기 위해 한 줄의 서지정보로 저장합니다.

```text
[20] Kim, E. (2026). Paper title. Food Chemistry, 100, 12345.
```

새 논문은 관리자 화면에서 목록 맨 위에 추가하고 번호를 최신 번호로 입력합니다.

## JSON을 직접 수정해야 하는 경우

GitHub에서 직접 편집할 수도 있지만 다음 사항을 지켜야 합니다.

1. 각 파일의 최상위 구조는 객체이며 반복 데이터는 `items` 배열 아래에 있습니다.
2. JSON의 마지막 항목 뒤에는 쉼표를 넣지 않습니다.
3. 큰따옴표 `"`를 임의로 삭제하지 않습니다.
4. 수정 후 **Commit changes**를 누르면 GitHub Pages에 반영됩니다.

일상적인 콘텐츠 업데이트에서는 관리자 UI를 사용하는 것을 권장합니다.
